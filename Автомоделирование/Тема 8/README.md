# Тема 8. Микроконтроллеры. Аналоговые и цифровые сигналы. ШИМ

Комплект для поэлементной загрузки в Moodle по структуре темы 7. Архив `Tema8_Moodle_publish.zip` содержит эти же материалы и README. Это не резервная копия курса: через «Восстановление» весь комплект не загружается.

Порядок элементов соответствует порядку разделов ниже. Копируйте блоки в соответствующие поля Moodle; HTML вставляйте в режиме исходного кода редактора. Рекомендуемые настройки предназначены для преподавателя.

## Задание — «Яркость по потенциометру»

Название:

```text
Задание — «Яркость по потенциометру»
```

Описание:

```html
<p>Соберите схему в Tinkercad Circuits (бесплатно, в браузере) или на учебной плате: потенциометр 10 кОм — крайние выводы на 5V и GND, средний на A0; светодиод через резистор 220 Ом — на вывод ~9.</p>
<ol><li>Напишите скетч, который читает A0 и задаёт яркость светодиода: <code>analogWrite(9, analogRead(A0) / 4);</code>. Добавьте вывод значений в монитор порта.</li><li>Установите ручку в пять положений и заполните таблицу: analogRead(), напряжение на A0 (по формуле), значение analogWrite(), коэффициент заполнения, среднее напряжение на выводе 9.</li><li>Объясните, почему значение analogRead() делят на 4.</li><li>Измените скетч так, чтобы светодиод был выключен, если напряжение на A0 меньше 1 В.</li></ol>
<p><strong>Критерии (10 баллов):</strong> схема собрана верно — 2; скетч работает — 3; таблица заполнена и расчёты верны — 3; объяснение деления на 4 — 1; доработка с порогом 1 В — 1.</p>
```

Файл: [zadanie_tema8.html](zadanie_tema8.html).

Загрузка: Создайте «Задание». Вставьте описание из блока выше либо из HTML-файла.

Рекомендуемые настройки:

```text
Тип ответа: файл и/или текст
Максимальная оценка: 10
Срок сдачи: установить по расписанию
```

## Состав и проверка

- Исключены IMS, дублирующий книгу, отдельная H5P-презентация и исходная инструкция с дополнительными модулями. Форум, опрос, семинар, вики и база данных не включены, как в теме 7.
- Из исходной инструкции выделены описание темы и полное описание задания. Из порядка работы убраны ссылки на исключённые элементы.
- Исходный XML ситуационных задач — банк вопросов с корнем `<quiz>`. Для «Лекции» подготовлен GIFT с сохранением условий, ответов и пояснений. Вопрос «верно/неверно» представлен выбором из двух ответов.
- Остальные шесть файлов скопированы без изменений. Проверены разбор XML и целостность ZIP.

Импорт в действующий Moodle не выполнялся. После загрузки проверьте занятие от имени студента: книгу и PDF, прохождение SCORM и запись оценки, переходы лекции, отправку задания, тест и анкету. Названия меню зависят от версии Moodle.
