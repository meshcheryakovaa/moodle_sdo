# Тема 11. Основные электрические компоненты: резисторы, конденсаторы, диоды, транзисторы

Комплект для поэлементной загрузки в Moodle по структуре темы 7. Архив `Tema11_Moodle_publish.zip` содержит эти же материалы и README. Это не резервная копия курса: через «Восстановление» весь комплект не загружается.

Порядок элементов соответствует порядку разделов ниже. Копируйте блоки в соответствующие поля Moodle; HTML вставляйте в режиме исходного кода редактора. Рекомендуемые настройки предназначены для преподавателя.

## Задание — «Транзистор управляет мотором»

Название:

```text
Задание — «Транзистор управляет мотором»
```

Описание:

```html
<p>Соберите в Tinkercad Circuits (или на учебной плате) схему управления двигателем постоянного тока от Arduino: вывод ~9 → резистор базы → транзистор n-p-n (например, TIP120 или BC337), двигатель от отдельного источника 9 В в цепи коллектора, обратный диод 1N4007 параллельно двигателю, общий GND.</p>
<ol><li>Примите ток двигателя 200 мА и β = 100. Рассчитайте ток базы с запасом и резистор базы. Выберите номинал из ряда E12.</li><li>Напишите скетч, который плавно разгоняет двигатель от 0 до полной скорости и останавливает его (analogWrite).</li><li>Объясните роль диода. Что произойдёт без него?</li><li>Добавьте потенциометр на A0 для регулировки скорости.</li></ol>
<p><strong>Критерии (10 баллов):</strong> схема собрана верно, диод включён правильно — 3; расчёт резистора базы — 2; скетч с плавным разгоном работает — 2; объяснение роли диода — 2; регулировка потенциометром — 1.</p>
```

Файл: [zadanie_tema11.html](zadanie_tema11.html).

Загрузка: Создайте «Задание». Вставьте описание из блока выше либо из HTML-файла.

Рекомендуемые настройки:

```text
Тип ответа: файл и/или текст
Максимальная оценка: 10
Срок сдачи: установить по расписанию
```

## Состав и проверка

- Исключены IMS, дублирующий книгу, отдельная H5P-презентация и исходная инструкция с дополнительными модулями. Форум, опрос, семинар, вики и база данных не включены, как в теме 7.
- Из исходной инструкции выделены описание темы и полное описание задания. Из порядка работы убраны ссылки на исключённые элементы.
- Исходный XML ситуационных задач — банк вопросов с корнем `<quiz>`. Для «Лекции» подготовлен GIFT с сохранением условий, ответов и пояснений. Вопрос «верно/неверно» представлен выбором из двух ответов.
- Остальные шесть файлов скопированы без изменений. Проверены разбор XML и целостность ZIP.

Импорт в действующий Moodle не выполнялся. После загрузки проверьте занятие от имени студента: книгу и PDF, прохождение SCORM и запись оценки, переходы лекции, отправку задания, тест и анкету. Названия меню зависят от версии Moodle.
