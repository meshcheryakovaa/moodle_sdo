# Тема 10. Чтение принципиальных электрических схем и условные обозначения

Комплект для поэлементной загрузки в Moodle по структуре темы 7. Архив `Tema10_Moodle_publish.zip` содержит эти же материалы и README. Это не резервная копия курса: через «Восстановление» весь комплект не загружается.

Порядок элементов соответствует порядку разделов ниже. Копируйте блоки в соответствующие поля Moodle; HTML вставляйте в режиме исходного кода редактора. Рекомендуемые настройки предназначены для преподавателя.

## Задание — «Чертим схему по ГОСТ»

Название:

```text
Задание — «Чертим схему по ГОСТ»
```

Описание:

```html
<p>Начертите по ГОСТ принципиальную схему устройства из двух прошлых занятий: Arduino Uno (прямоугольник с подписанными выводами), светодиод с токоограничивающим резистором на выводе D9, кнопка на выводе D2 и потенциометр на входе A0. Можно чертить в KiCad, sPlan, draw.io или от руки на клетчатой бумаге.</p>
<ol><li>Используйте УГО по ГОСТ (резистор — прямоугольник 10×4 мм, светодиод — диод со стрелками).</li><li>Присвойте позиционные обозначения: R1, R2, HL1 (или VD1), SB1, DD1 или A1 для платы.</li><li>Покажите питание и общий провод метками +5V и GND.</li><li>Составьте перечень элементов: позиционное обозначение, наименование и номинал, количество.</li><li>Опишите в 3–4 предложениях путь тока через светодиод.</li></ol>
<p><strong>Критерии (10 баллов):</strong> УГО соответствуют ГОСТ — 3; позиционные обозначения верны — 2; соединения и метки цепей без ошибок — 2; перечень элементов полный — 2; описание пути тока — 1.</p>
```

Файл: [zadanie_tema10.html](zadanie_tema10.html).

Загрузка: Создайте «Задание». Вставьте описание из блока выше либо из HTML-файла.

Рекомендуемые настройки:

```text

Максимальная оценка: 10
Срок сдачи: установить по расписанию
```

## Состав и проверка

- Исключены IMS, дублирующий книгу, отдельная H5P-презентация и исходная инструкция с дополнительными модулями. Форум, опрос, семинар, вики и база данных не включены, как в теме 7.
- Из исходной инструкции выделены описание темы и полное описание задания. Из порядка работы убраны ссылки на исключённые элементы.
- Исходный XML ситуационных задач — банк вопросов с корнем `<quiz>`. Для «Лекции» подготовлен GIFT с сохранением условий, ответов и пояснений. Вопрос «верно/неверно» представлен выбором из двух ответов.
- Остальные шесть файлов скопированы без изменений. Проверены разбор XML и целостность ZIP.

Импорт в действующий Moodle не выполнялся. После загрузки проверьте занятие от имени студента: книгу и PDF, прохождение SCORM и запись оценки, переходы лекции, отправку задания, тест и анкету. Названия меню зависят от версии Moodle.
