## Как загрузить

1. Создайте раздел темы 7. Откройте `opisanie_temy7.html` в браузере и скопируйте содержимое в редактор описания. При вставке через режим HTML используйте содержимое `<body>`. Аналогично вставляется описание задания.
2. **Глоссарий:** создайте элемент, затем «Импорт записей» → XML → текущий глоссарий; включите импорт категорий. В файле 24 термина.
3. **Книга:** создайте книгу → «Импорт главы» (может находиться в меню «Ещё») → каждый HTML-файл представляет одну главу → загрузите ZIP. Проверьте порядок глав и отображение схем.
4. **Файл:** загрузите PDF в ресурс «Файл».
5. **SCORM:** загрузите ZIP без распаковки в «Пакет SCORM». Максимум — 100, метод — наивысшая оценка, попытки — неограниченно, выполнение — статус «Пройден». Порог зачёта в пакете — 80 %.
6. **Лекция:** создайте элемент → «Импорт вопросов» → формат **GIFT** → `lesson_situations_tema7.gift`. Включите повтор ответа, максимум попыток — 3. После импорта проверьте переходы: правильный ответ — следующая страница, неправильный — текущая; после последней задачи — конец лекции. В комплекте 8 задач с ответами и пояснениями.
7. **Задание:** вставьте `zadanie_tema7.html`. Тип ответа — файл (фото решения / документ) и/или текст; максимальная оценка — 10. Срок установите по расписанию. В описании сохранены шесть вариантов и критерии оценки.
8. **Тест:** банк вопросов → импорт → «Формат Moodle XML» → `test_bank_tema7.xml`. Затем создайте «ТЕСТ 7» и добавьте вопросы из категории темы 7. Рекомендуется: 25 минут, 2 попытки, высшая оценка, максимум — 10. Банк содержит 21 вопрос, включая эссе «РАСЧ-05» с ручной проверкой; для полностью автоматического теста исключите эссе.
9. **Обратная связь:** создайте анонимную анкету → редактирование вопросов → импорт → `feedback_tema7.xml`.

Названия меню зависят от версии Moodle. Проверьте занятие через просмотр от имени студента: книгу и PDF, прохождение SCORM и запись оценки, переходы лекции, отправку задания, тест и анкету. Импорт на действующем Moodle в рамках подготовки комплекта не выполнялся.

## Что изменено при отборе

- Исключены IMS (дублирует книгу), отдельная презентация H5P и большая исходная инструкция с дополнительными модулями. Форум, опрос, семинар, вики и база данных не включены: их нет в показанной структуре занятия.
- Описание темы приведено к выбранному набору элементов: убраны ссылки на H5P, форум и опрос.
- Из исходной инструкции выделено описание задания с таблицей вариантов и критериями.
- Исходный `lesson_situations_tema7.xml` имеет корень `<quiz>` и предназначен для банка вопросов. Вместо ошибочно указанного в исходной инструкции импорта Moodle XML в «Лекцию» подготовлен GIFT. Сохранены условия, варианты, правильные ответы и пояснения; вопрос «верно/неверно» представлен выбором из двух ответов.
- Остальные шесть файлов скопированы без изменений. Библиотеки H5P для выбранного комплекта не требуются.
