### Заполнение тематического плана (раздел 2.2)

План един для всех специальностей. Каждая тема занимает блок строк. Профессиональные примеры подбираются при подготовке учебных материалов. Отдельные графы и строки по специальностям в тематическом плане не предусмотрены.

1. **Графа 1. Наименование разделов и тем.** Указать «Введение» или «Тема N. Краткое название темы». Оформить полужирным курсивом, по левому краю и по верхней границе блока. Ячейку объединить по вертикали на все строки темы.
2. **Графа 2. Содержание учебного материала и формы организации деятельности обучающихся.** В первой строке указать полное официальное название занятия в формате «Лекция N. …» или «Практическая работа N. …». Выделить всю строку названия полужирным курсивом. У лекций и практических работ самостоятельная нумерация.
3. Ниже в той же графе раскрыть **дидактические единицы**. Каждую поместить в отдельную строку таблицы, оформить обычным прямым шрифтом, выровнять по левому краю. Нумерацию начать с «1.» внутри каждой темы. Для лекций использовать краткие предметные формулировки: понятия, свойства, связи, методы. Для практических работ называть изучаемые операции и способы проверки результата. Образец формулировки — «Сопоставимость величин и единиц измерения».
4. **Графы 3 и 4.** Указать часы и коды компетенций один раз для всей темы. В каждой графе объединить ячейки по вертикали на высоту блока. Часы выровнять по центру, коды — по левому краю. Горизонтальные линии между дидактическими единицами проходят только через графу 2.

**Пример заполнения графы 2**

| Строка в блоке темы | Текст |
|---|---|
| Официальное название | ***Лекция 8. Сравнение источников. Критерии сопоставления и условия применимости данных.*** |
| Первая дидактическая единица | 1. Объект, критерии и условия сравнения. Сопоставимость величин и единиц измерения. |
| Вторая дидактическая единица | 2. Сравнительная таблица. Расхождения в источниках и ограничения вывода. |

**Границы.** В таблице объёма дисциплины внешние и внутренние линии одинарные чёрные, 0,75 пт. В остальных таблицах с сеткой — одинарные, 0,5 пт. Таблица содержания оформлена без сетки.

**Проверка перед сдачей.** После окончательной вёрстки сверьте номера страниц в содержании. В режиме предварительного просмотра проверьте переходы между книжной и альбомной ориентацией, видимость правой границы тематического плана и соответствие объединённых ячеек строкам каждой темы.
