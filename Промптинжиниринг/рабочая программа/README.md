# Оформление рабочей программы «Промптинжиниринг»

Образец — файл `РП_ИОТ_Автомоделирование_МещеряковАА(2).docx`. Параметры ниже воспроизводят оформление этого документа. При переносе в Word выбирайте настройки соответствующего раздела.

## Страницы и текст

| Элемент | Как оформить в Word |
|---|---|
| Страница | А4. Основной текст — в книжной ориентации. Для тематического плана использовать разрывы разделов и альбомную ориентацию, после плана вернуться к книжной. |
| Поля | В начале образца слева 22,5–25 мм, справа 15 мм, сверху около 19,4 мм, снизу около 24 мм. В книжном разделе перед тематическим планом — по 20 мм. В альбомном разделе слева и справа по 20 мм, сверху 15 мм, снизу 12,5 мм. После плана — по 20 мм, кроме правого поля 15 мм. |
| Основной текст | Стиль «Обычный», Times New Roman, 12 пт, прямое начертание. Пояснительные абзацы выравнивать по ширине. |
| Титульный лист | Наименование организации — 14 пт, по центру. «РАБОЧАЯ ПРОГРАММА» — 14 пт, полужирными прописными, по центру. Блок утверждения сместить вправо отступом абзаца (в образце 10 см от левого поля). Город и год — по центру. |
| Сведения о разработке и рассмотрении | Выравнивание по ширине, первая строка 1,25 см, межстрочный интервал 1,5. Такой же межстрочный интервал использован в списке источников. В других разделах интервалы различаются. |
| Заголовки | «СОДЕРЖАНИЕ» — по центру, полужирным. Названия основных разделов — прописными, полужирным. Подразделы — с номером и названием полужирным обычного регистра, например «2.1. Объем учебной дисциплины и виды учебной работы». |
| Перечни компетенций | Каждая компетенция — с нового абзаца, сначала код, затем формулировка. В перечне ОК типичный отступ первой строки 1 см, интервал после абзаца 6 пт. |

## Таблицы

Основной кегль в ячейках — 12 пт. Ширины ниже округлены по сетке таблиц в образце и приведены слева направо. При изменении объёма текста сохраняйте назначение столбцов и проверяйте расположение правой границы на странице.

| Таблица | Столбцы и ширина | Оформление |
|---|---|---|
| Содержание | Название раздела / страница — 152 / 18 мм | Без видимой сетки. Текст и номера страниц — 14 пт. Номера помещать в отдельные ячейки. |
| Планируемые результаты | Код / умения / знания — 22 / 78 / 70 мм | Шапка по центру, прямое обычное начертание. Коды в первом столбце — по центру, в образце 10 пт. В двух остальных столбцах — списки с выравниванием по ширине. |
| Объём дисциплины и виды работы | Вид работы / объём часов — 139 / 32 мм | Шапка полужирная, по центру. Часы по центру. Основные и итоговые показатели выделять полужирным, вложенные виды работ — отступом слева. |
| Тематический план | Раздел или тема / содержание и формы работы / часы / компетенции — 45 / 173 / 16 / 30 мм | Альбомная страница. Шапка и строка номеров граф 1–4 — полужирным курсивом, по центру. Часы — по центру. Для темы из нескольких строк объединять по вертикали ячейки с общим названием, часами и компетенциями. Название темы и обобщающую формулировку выделять полужирным курсивом, подробности занятия набирать прямым шрифтом. |
| Контроль результатов обучения | Результаты / показатели / формы и методы оценки — 49 / 73 / 54 мм | Шапка — по центру, полужирным курсивом. Строку группы результатов, например «Умения», объединять на всю ширину и выделять полужирным курсивом. |
| Оценка общих и профессиональных компетенций | Компетенция / показатели / формы и методы контроля. Для ОК — 55 / 70 / 45 мм, для ПК — 59 / 54 / 62 мм | Шапка — полужирным прямым шрифтом, по центру. В первом столбце помещать код и формулировку, во втором — показатели, в третьем — способы контроля. |

**Границы.** В таблице объёма дисциплины внешние и внутренние линии одинарные чёрные, 0,75 пт. В остальных таблицах с сеткой — одинарные, 0,5 пт. Таблица содержания оформлена без сетки.

**Проверка перед сдачей.** После окончательной вёрстки сверьте номера страниц в содержании. В режиме предварительного просмотра проверьте переходы между книжной и альбомной ориентацией, видимость правой границы тематического плана и соответствие объединённых ячеек строкам каждой темы.
